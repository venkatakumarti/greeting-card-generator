# 💌 Greeting Card Generator

A fun and interactive web app that generates personalized greeting cards based on user input. Choose an occasion like Birthday, Graduation, Thank You, or Get Well Soon — type a name, click a button, and get a beautiful, themed message!

Built using **HTML**, **CSS**, and **JavaScript** — perfect for beginners learning DOM manipulation, event handling, and dynamic content updates.

---

## 🔧 Built With

- **HTML** – For structure and form elements
- **CSS** – For styling and themed backgrounds
- **JavaScript** – For logic and dynamic greeting generation

No frameworks, no libraries — just clean, vanilla web technologies!

---

## 🚀 Features

- Personalized greetings based on user’s name
- 4 selectable occasions:
  - 🎉 Birthday
  - 🎓 Graduation
  - 🙏 Thank You
  - 🌸 Get Well Soon
- Themed background colors for each occasion
- Responsive layout (works on mobile and desktop)
- Instant update without page reload

---
